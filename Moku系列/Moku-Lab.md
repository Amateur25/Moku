# Moku-Lab

![[Moku-Lab.png]]

**已停产（EOL）**。官方推荐替代品：[[Moku-Pro]]，提供 600 MHz 带宽、10+18 位 ADC 混合技术和 4 通道并行测量能力。

## 模拟 I/O

- 2 模拟输入：DC-200 MHz，500 MSa/s
- 2 模拟输出：DC-300 MHz，1 GSa/s
- 本底噪声：< 30 nV/√Hz @ 100 kHz

## 仪器与功能

集成 14+ 种仪器。支持多仪器并行模式和 Moku Cloud Compile（MokuOS 3.0 起）。支持 GenInst Studio 以自然语言创建定制仪器。

## 应用案例

- **暗物质探测**：Alberta 大学研究人员使用 Moku:Lab [[锁相放大器]] 开发超灵敏设备，改进暗物质探测技术。
- **Allan 方差测量**：使用 Moku:Lab [[相位表]] 进行 Allan 方差测量，量化时钟电路和振荡器的稳定性（亚微弧度精度，数字锁相环架构）。

## 特点

- 200 MHz 带宽，低延迟控制
- 经济实惠的多仪器集成
- 基于 FPGA 的可重构硬件平台
- PC / Mac / iPad 控制，Python / MATLAB / LabVIEW API
