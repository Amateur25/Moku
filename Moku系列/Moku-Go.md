# Moku-Go

![[Moku-Go.png]]

入门级可重构测试测量硬件，便携多功能，同级别最佳性价比。如需更高性能可升级至 [[Moku-Pro]]（600 MHz）或旗舰级 [[Moku-Delta]]（2 GHz）。

## 模拟 I/O

- 2 模拟输入：30 MHz，125 MSa/s
- 2 模拟输出：20 MHz，125 MSa/s

## 数字 I/O

- 16 通道 DIO，每通道 125 MSa/s
- 支持逻辑分析仪/码型发生器

## 内置可编程电源

内置双路可编程电源输出，可直接为被测电路供电。

## 仪器与功能

集成 15+ 种仪器，包括示波器、PID 控制器、锁相放大器、激光锁频/稳频器等——这些高级仪器在同级别产品中罕见。支持 FPGA 自定义编程、API（Python/MATLAB/LabVIEW）集成。支持 GenInst Studio 以自然语言创建定制仪器。

## 教育应用

- **Oregon State University eCampus**：自动化教学案例，Moku:Go 提供直观 UI 设计，强化基本概念，加速进阶内容理解。
- **工程教育现代化**：适用于音频、电力电子、模拟/数字电路设计教学，从实验到教学随处便携。
