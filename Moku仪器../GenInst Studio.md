# GenInst Studio

GenInst Studio 是 Moku 平台上的 AI 驱动仪器创建工具。用户通过自然语言提示即可生成经过验证的、面向特定应用的定制仪器，无需 FPGA 开发经验，可在几分钟内部署到 Moku 设备。

## 定位

GenInst Studio 与 Moku 自定义仪器（[[GenInst]]）协同工作，为用户提供从自然语言描述到 FPGA 部署的端到端定制仪器开发体验。它将 AI 辅助设计与 Moku 多仪器并行模式深度集成，允许自定义仪器与标准仪器在同一设备上实时协同运行。用户无需具备 FPGA 开发经验，即可通过自然语言创建应用特定仪器，并可在多仪器模式下与标准仪器热插拔组合。

## AI 工作流程

1. **自然语言描述**：用户通过自然语言提示描述所需的信号处理或测量功能。
2. **AI 生成**：GenInst Studio 基于描述自动生成定制仪器算法（对应 FPGA 上的自定义仪器实现）。
3. **验证**：自动对生成的定制仪器算法进行验证，确保功能正确与可部署性。
4. **部署**：验证通过后，编译并部署到 Moku 设备的 FPGA 上，在 Moku 多仪器并行模式下与 [[锁相放大器]]、[[示波器]]、[[PID 控制器]] 等标准仪器协同运行。
