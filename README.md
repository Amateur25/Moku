## 记录原则

- 产品参数优先引用 Liquid Instruments 官方资料，并记录来源链接和适用型号。
- 软件/API 内容注明软件、固件或库版本；无法确认时明确标为未知。
- 实验和故障记录写明设备型号、连接方式、软件版本、现象和验证结果。
- 翻译、摘要或 AI 辅助生成的内容应标注其性质，并由维护者核对关键参数。
- 保留原始资料和图片的文件名、来源及相对路径。
