# 如何通过直接以太网电缆将我的Moku:Lab连接到 Windows PC

## 无需路由器或交换机的直接以太网连接

要通过以太网电缆将您的Moku:Lab连接到 Windows PC（无需路由器或交换机），您需要配置网络并为Moku:Lab分配一个静态 IP 地址。

**配置PC网络：**

1. 在电脑上进入“设置”\-\>“网络和 Internet”\-\>“以太网”

2. 选择“更改网络属性”和“编辑 IPv4 设置”

3. 配置 IPv4 设置，如下所示：

IP：192\.168\.1\.168

子网掩码：255\.255\.255\.0

网关：192\.168\.1\.254

DNS：192\.168\.1\.201

备用DNS：192\.168\.1\.203

![image\.png](/image.png)

注意：根据您使用的 Windows 操作系统版本，您可能需要设置子网前缀长度，将其设置为 24。

**修复Moku的 IP：**

1. 使用iPad通过Wifi连接Moku

2. 在“选择您的设备”菜单中，点击您的Moku ，然后点击左下角的设置图标，这将打开“设备设置”菜单

3. 在“设备设置”菜单中，点击以太网，打开“通过以太网连接”

4. 将“配置”设置为手动，然后将 IP 地址设置为 192\.168\.1\.167，子网掩码为 255\.255\.255\.0

5. 点击“应用”

现在您应该能够使用 IP 地址 192\.168\.1\.167 通过以太网电缆连接到您的Moku 。
