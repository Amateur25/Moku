# Moku:Go 校准与功能验证

## 4. 操作流程（Procedure）

在执行操作流程前，确保已经安装了moku的python包，如果没有安装请确保python版本并安装‘moku’

```bash
python -m pip install --upgrade moku
```

### 4.1 校准（Calibration）

**步骤 1：连接设备**

使用 USB-C 转 USB-C 数据线，将电脑与 Moku:Go 连接。

**步骤 2：获取设备 IP 地址**

1. 打开 Moku:Go Desktop App。
2. 在设备列表中找到对应的 Moku:Go（设备名称格式为 `Moku-######`）。
3. 右键单击设备，将鼠标悬停在 `Device Info` 菜单项上。
4. 在展开的子菜单中，单击 `Copy IP address`，复制设备的 IP 地址。

**步骤 3：运行校准脚本**

打开终端，进入 `calibrate_mokugo.py` 文件所在的目录。

执行以下命令，并将示例 IPv6 地址替换为实际复制的设备地址：

```bash
python calibrate_mokugo.py [设备IP地址]
```

**步骤 4：按照终端提示完成校准**

1. 将外部电源的两个通道分别设置为 `+1 V`，并连接至 Moku:Go 的 Input 1 和 Input 2，然后按回车键继续。
2. 使用万用表测量 Moku:Go 的 Output 1 和 Output 2 电压。
   - 万用表正表笔接 BNC 输出端的中心导体。
   - 万用表负表笔接 BNC 接口外侧的接地部分。
   - 将两个输出端测得的电压值分别输入终端，单位为伏特（V）。
3. 将外部电源的两个通道分别设置为 `−1 V`，按终端提示按回车键继续。
4. 再次测量 Output 1 和 Output 2 的电压，并将测量值输入终端。

**步骤 5：等待校准完成并重启设备**

校准脚本完成校准重置操作后，终端会显示新的命令提示符，表示脚本执行结束。

等待至少 **60 秒**，然后拔下 USB-C 连接线，使 Moku:Go 断电重启。

### 4.2 ADC 检查（ADC Check）

**步骤 1：检查零点偏移**

1. 在 Moku:Go Desktop App 中连接设备。
2. 打开 `Oscilloscope`（示波器）仪器，并切换至 `Voltmeter`（电压表）选项卡。
3. 保持 Input 1 和 Input 2 处于开路状态，不连接任何信号。
4. 使用电压表功能测量 Channel A 和 Channel B 的平均偏移电压。

**步骤 2：检查直流增益**

1. 将 Moku:Go 的 Input 1 和 Input 2 重新连接至外部电源。
2. 向两个输入端分别施加 `+1 V` 直流电压。
3. 使用软件电压表测量对应通道的直流电平。
4. 将测量结果与下表中的验收限值进行比较。

**表 1：ADC 验证限值**

| 参数 | 验证点 | 允许范围 |
|---|---:|---:|
| 平均偏移电压 | 0.000 V | ±0.05 V |
| 正直流电平（增益） | 1.000 V | ±0.05 V |

如果 ADC 的平均偏移电压或直流电平增益超出上述范围，应重新执行第 4.1 节的校准流程。

### 4.3 DAC 检查（DAC Check）

校准成功后，进行 DAC 输出验证。也可以使用外部示波器代替 Moku:Go 自身的输入回环测量。

**步骤 1：建立输出回环**

1. 断开 Moku:Go 输入端与外部电源之间的 BNC 连接线。
2. 将 Output 1 连接至 Input 1，将 Output 2 连接至 Input 2。

**步骤 2：配置波形发生器**

1. 在 `Oscilloscope` 仪器中打开集成的 `Waveform Generator`（波形发生器）。
2. 将 Output 1 和 Output 2 均配置为正弦波。
3. 将信号频率设置为 `1 MHz`，峰峰值幅度设置为 `1 Vpp`。

**步骤 3：检查输出信号**

在示波器界面观察输出波形，并测量正弦波的幅度与频率。

**表 2：DAC 验证限值**

| 参数 | 验证点 | 允许范围 |
|---|---:|---:|
| 正弦波幅度 | 1.000 V | ±0.005 V |
| 正弦波频率 | 1.000 MHz | ±0.005 MHz |

### 4.4 可编程电源检查（PPSU Check）

**步骤 1：打开电源设置**

在 Moku:Go Desktop App 中连接设备并打开 `Oscilloscope` 仪器。

**步骤 2：配置可编程电源**

单击菜单按钮，在下拉菜单中选择 `Power supply`（电源）。

启用以下四路可编程电源，并设置对应电压：

| 电源通道 | 设定电压 |
|---|---:|
| PPSU1 | 5 V |
| PPSU2 | 16 V |
| PPSU3 | 5 V |
| PPSU4 | 5 V |

**步骤 3：测量输出电压**

使用万用表测量各路 PPSU 输出端的电压：

- 万用表正表笔接对应的红色 PPSU 输出端子。
- 万用表负表笔接任意一个黑色接地端子。
- 依次测量 PPSU1、PPSU2、PPSU3 和 PPSU4。

**表 3：PPSU 验证限值**

| 电源通道 | 验证点 | 允许范围 |
|---|---:|---:|
| PPSU1 | 5.000 V | ±0.020 V |
| PPSU2 | 16.000 V | ±0.020 V |
| PPSU3 | 5.000 V | ±0.020 V |
| PPSU4 | 5.000 V | ±0.020 V |

### 4.5 数字 I/O 检查（Digital I/O Check）

**步骤 1：连接数字 I/O 线缆**

将数字 I/O（DIO）线缆连接至 Moku:Go。

**步骤 2：检查电源引脚**

使用万用表测量 DIO 线缆上的电源引脚：

- 红色线对应的电源引脚：测量电压应接近 `+5 V`。
- 橙色线对应的电源引脚：测量电压应接近 `+3.3 V`。

原始文档将上述电压是否正常作为该项检查的验收依据，没有给出具体的数值容差。

### 4.6 Wi-Fi 与以太网检查（Wi-Fi and Ethernet Check）

**步骤 1：检查以太网连接**

1. 拔下 Moku:Go 的 USB-C 连接线。
2. 将以太网线连接至 Moku:Go。
3. 确保电脑与 Moku:Go 位于同一网络和子网。
4. 等待设备重新出现在 Moku:Go Desktop App 的设备选择界面中。

**步骤 2：检查 Wi-Fi 可发现性**

1. 拔下以太网线。
2. 打开电脑的本地无线网络列表。
3. 检查是否能够发现名称格式为 `Moku-######` 的 Moku:Go 无线网络，其中 `######` 对应设备序列号。

如果该无线网络能够出现在电脑的无线网络列表中，则按照原始文档的标准，该项检查通过。

**步骤 3：结束检查**

拔下 Moku:Go 的磁吸式电源适配器，并断开连接在设备输入端和输出端的其他线缆。

至此，Moku:Go 的质量检查流程结束。
